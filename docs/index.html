Changelog

What's new in ThreatDock v1.1

NEW Real-Time WebSocket

  • Socket.IO server with live events: alerts:updated, source:health, correlations:updated, fetch:complete
  • Frontend auto-refresh for dashboard, alerts, and IntelOperations
  • Live source-health pulse indicators with CSS animation
  • Nginx WebSocket upgrade proxy

PERF Batch INSERT (10-50x Faster)

  • Bulk INSERT (1000 rows) for alerts, indicators, and CVE enrichment
  • Settings cache with 5-min TTL — eliminates redundant DB queries per fetch cycle
  • Parallel notifications via Promise.allSettled — 4 channels concurrent
  • CVE enrichment skips data refreshed within 24 hours
  • N+1 query elimination: word-index O(1) asset matching
  • Batch INSERT for correlation findings INSERT

NEW API Documentation

  • OpenAPI 3.0 specification served at /api/docs.json
  • Self-hosted Swagger UI at /api/docs — no CDN required
  • All endpoints documented with request/response schemas
  • Interactive "Try it out" for each endpoint

NEW PWA Support

  • Service worker with network-first navigation strategy
  • Manifest.json for standalone install mode
  • Push notification endpoint POST /api/notify
  • Self-destruct mode to clear stale caches on version mismatch

NEW Rate Limiter

  • In-memory sliding window rate limiter
  • Auth endpoints: 120 requests/minute per IP
  • API endpoints: 600 requests/minute per IP
  • X-Forwarded-For aware for correct IP detection behind Nginx

PERF Infrastructure & Database

  • PostgreSQL connection pool increased 10→25
  • 6 new composite database indexes for time-series queries
  • Redis 7 service with Bull queue support (graceful in-memory fallback)
  • Weekly data retention cron (prunes alerts >90 days)
  • PostgreSQL partitioning migration script

NEW Pagination (Backward-Compatible)

  • GET /api/alerts — optional ?page=&limit= returns {data, total, page, limit}
  • GET /api/assets — same pagination format
  • GET /api/intelligence/indicators and /correlations — paginated
  • All endpoints return legacy array format when no pagination params given

NEW Manual Fetch & Timeout Safety

  • POST /api/ingestion/fetch — trigger immediate source ingestion
  • "Fetch Sources" button in IntelOperations UI
  • 30-minute automatic lock reset for stuck ingestion runs
  • Per-source timeout (60s max) via Promise.race

FIX Bug Fixes

  • Deduplication before batch INSERT to prevent ON CONFLICT errors
  • Content-Security-Policy relaxed for Swagger UI (local assets)
  • IP detection via X-Forwarded-For behind nginx proxy
  • Service worker cache-busting with no-cache nginx headers
  • TimeoutOverflowWarning suppression via --no-warnings flag
